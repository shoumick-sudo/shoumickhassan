Ratings and interpretation

Score = sum of five 0–4 ratings ÷ 20 × 100. Missing ratings invalidate the submission; they are not imputed as zero. A valid zero is an observed demonstration rating.

Original professional work and this reconstruction

Applicant-confirmed NSDA contributions

Designed and tested Google Forms linked to Sheets; consolidated officer submissions; wrote Python scripts to clean data, flag issues, calculate monitoring summaries and generate charts or tables. Built interactive STP-monitoring dashboards using Metabase, Google Sheets and Python/web-based tools, with data preparation, indicator calculations, filters, import/refresh processes and reconciliation checks.

The applicant confirms using the dashboards personally and knows that NSDA colleagues and management used them. Monitoring outputs supported management review, record corrections and provider/officer follow-up. Update methods across the workstream included scheduled/automated processes, manual rebuilds, connected-database queries, linked Sheets and manual imports. These methods are not asserted to belong to one integrated architecture.

Historical dates, original dashboard files, exact frameworks and quantified outcomes are not established by the current reconstruction. Contributions are applicant-confirmed experience; documentary corroboration is tracked separately and privately.
